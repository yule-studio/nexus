## 1. 한 줄

스타트업 대상 **AWS 크레딧 + 무료 지원 + 학습 자료** 프로그램. 액셀러레이터 / VC 추천이 있으면 큰 크레딧.

## 2. 종류

| Tier | 크레딧 | 조건 |
| --- | --- | --- |
| **Founders** | $1,000 | 누구나 (web fil-in) |
| **Portfolio** | $1,000 ~ $25,000 | 액셀러레이터 / VC 추천 |
| **Plus** | $5,000 ~ $100,000+ | 시리즈 A+ |

+ Business Support 일시 무료 + AWS IQ 크레딧.

## 3. 함정

- 1회성 — 사용 만료 (보통 1-2 년)
- 신청 / 승인 시간 (수 주)
- Bedrock / GPU 같은 비싼 자원은 빨리 소진
