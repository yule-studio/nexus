## 2. Support 플랜 5 단계

| 플랜 | 비용 | 핵심 |
| --- | --- | --- |
| **Basic** | 무료 | 24/7 계정 / 청구만 |
| **Developer** | $29~ / 월 | 영업시간 기술 질문 |
| **Business** | $100~ / 월 (사용량) | 24/7 + API + Trusted Advisor 전체 |
| **Enterprise On-Ramp** | $5,500~/월 | + TAM lite |
| **Enterprise** | $15,000~/월 | + 전담 TAM + 15분 응답 |

→ 프로덕션 운영 = **Business 최소**. 큰 조직 / 핵심 인프라 = Enterprise.
