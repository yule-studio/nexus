## 1. 한 줄

**AWS 인증 전문가 매칭 마켓플레이스** — 단발성 작업 (4-40시간) 을 AWS 청구서로 결제. Upwork 의 AWS 버전.

## 2. 왜 / 언제

- 단발성 컨설팅 (Terraform 설정 / IAM 정리 / 비용 점검)
- 사내 전문가 부재 시 한 시간 단위 도움
- AWS 청구서로 통합 결제

## 3. 함정 / 대안

- 작은 작업 (수 시간) 전용
- 큰 프로젝트 = Pro Services / 파트너
- 한국 시간대 / 한국어 전문가 풀 한정 — 영어 OK 권장
