## 1. 한 줄

5 단계 기술 지원 플랜 — Basic (무료) ~ Enterprise ($15K+/월). Business 부터 24/7 + Trusted Advisor 전체 + API.

## 2. 5 단계

| 플랜 | 응답 SLA | 비용 |
| --- | --- | --- |
| Basic | X (계정 / 청구만) | 무료 |
| Developer | 업무시간 24h | $29~/월 |
| Business | **prod 1h, urgent 24/7** | $100~ (사용 7%) |
| Enterprise On-Ramp | 30분 | $5,500~/월 |
| **Enterprise** | **15분 + TAM 전담** | $15,000~/월 |

## 3. 선택

- 개인 / 학습 = Basic
- prod 운영 = **Business 최소**
- 큰 조직 / 미션 크리티컬 = Enterprise (TAM 가치 큼)
