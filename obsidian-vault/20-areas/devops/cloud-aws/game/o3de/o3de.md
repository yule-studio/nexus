## 1. 한 줄

오픈소스 게임 엔진 (Linux Foundation, AWS 후원). 옛 Lumberyard 의 후신. Apache 2.0 라이선스 — Unreal / Unity 의 대안.

## 2. 함정

- 사용 빈도 매우 낮음 — 게임 엔진 시장은 Unreal / Unity / Godot 가 표준
- AWS 와의 통합 강함 (GameLift / GameKit) — AWS 가 핵심 후원자
- 학습 곡선 큼
