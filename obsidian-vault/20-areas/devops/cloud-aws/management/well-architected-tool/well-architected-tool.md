## 1. 한 줄

AWS Well-Architected Framework **6 pillar** (Operational Excellence / Security / Reliability / Performance / Cost / Sustainability) 자가 점검 워크북.

## 2. 왜 / 언제

- 응용 아키텍처 review (분기 / 주요 변경 시)
- 개선 액션 도출 (HRI — High Risk Item)
- Pro Services / 파트너 리뷰 사전 준비
- Custom Lens — 사내 / 도메인 표준

## 3. 함정

- 단순 self-assessment — 실 점검 / 개선 후속 액션이 진짜 가치
- 6 pillar 깊이 학습은 별도 (whitepaper)
- 무료
