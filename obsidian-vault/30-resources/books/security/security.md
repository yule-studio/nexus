## 1. Web Application Security

### 입문
- ⭐ **The Tangled Web** (Michal Zalewski, No Starch, 2011)
  - 주제: web 보안 모델의 古典
  - 원서: [No Starch](https://nostarch.com/tangledweb)

### 중급
- ⭐ **Web Application Security (2nd)** (Andrew Hoffman, O'Reilly, 2024) 🆕
  - 주제: modern web 보안 (recon / attack / defense)
  - 원서: [O'Reilly](https://www.oreilly.com/library/view/web-application-security/9781098143923/)
  - 🇰🇷 [웹 애플리케이션 보안](https://search.kyobobook.co.kr/search?keyword=웹+애플리케이션+보안)

- **The Web Application Hacker's Handbook (2nd)** (Dafydd Stuttard, Marcus Pinto, Wiley, 2011) 📖
  - 주제: pentesting 의 古典
  - 🇰🇷 [웹 해킹 & 보안](https://search.kyobobook.co.kr/search?keyword=웹+해킹+보안+완벽+가이드)
  - 원서: [Wiley](https://www.wiley.com/en-us/The+Web+Application+Hacker%27s+Handbook%3A+Finding+and+Exploiting+Security+Flaws%2C+2nd+Edition-p-9781118026472)

### 고급
- **Real-World Bug Hunting** (Peter Yaworski, No Starch, 2019)
  - 주제: bug bounty 실전
  - 원서: [No Starch](https://nostarch.com/bughunting)
