## 3. 운영 규칙

1. 외부 요약 / 발췌 X — URL + 강점 / 추천 경로만.
2. star 수 보다 **코드 품질 / 학습 가치** 우선.
3. 회사 production framework (Linux / Postgres / Kubernetes 등) 의 reading guide 별도 작성 권장.
4. fork 가 많은 reference 구현 우선 (raywenderlich style "the right way").
5. 죽은 repo / archived 표시.

## 4. 마커

- ⭐ = 분야 essential
- 📖 = 코드 통독 가치 (1+ 주 투자)
- 🏗️ = production scale (대규모)
- 🎓 = 학습 / 교육용 (작고 명확)
- 🆕 = 최근 활발 (2024+)
