## 3. 운영 규칙

1. 외부 요약 / 발췌 X — 공식 URL + 강점만.
2. 한 프로젝트 = 한 entry. version-specific docs 는 sub-bullet.
3. RFC / W3C / ISO 같은 표준은 별도 (`standards-rfc`).
4. 공식 docs 가 사실상 책 / 강의 역할이면 books / lectures 에 cross-link.
5. 죽은 링크 / EOL 프로젝트 발견 시 archive 표시.

## 4. 마커

- ⭐ = 해당 분야 essential
- 🆓 = 항상 무료 (대부분 공식 docs)
- 📖 = 책 처럼 통독 가치 있음
- 🆕 = 최근 활발 (2024+)
