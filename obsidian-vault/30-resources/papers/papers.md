## 3. 운영 규칙

1. 외부 요약 / 발췌 X — 1 줄 강점만.
2. arXiv / 학회 site / 회사 archive 의 직접 링크.
3. seminal (시발) 논문만 포함 — best paper / 영향력 큰 것.
4. 깊이 읽은 논문은 별도 노트 (`30-resources/papers/<slug>.md`) 로 추출.
5. 한국어 논문은 별도 한국 학회 / arXiv 한국 저자.

## 4. 마커

- ⭐ = 해당 분야 seminal
- 🆓 = arXiv / 무료 공개
- 🏆 = best paper award
- 🆕 = 최근 (2024+)
